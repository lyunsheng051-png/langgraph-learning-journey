## 依赖复现

前两章的直接运行依赖只有 LangGraph；第 3 篇增加 python-docx 和 pypdf 进行格式解析。langchain-core、检查点、SDK 等是安装 LangGraph 时解析得到的传递依赖，示例没有主动使用模型、检查点、网络 SDK 或追踪服务。

- Python 范围：`>=3.12,<3.13`；`.python-version` 指定 `3.12`。
- 第 1 篇声明 `langgraph>=1.0,<2.0`，第 2—3 篇声明 `langgraph==1.2.16`；三章各自的 `uv.lock` 均锁定为 `1.2.16`。
- 第 3 篇的 `fixtures` 依赖组用于重建样例，需要 reportlab；正常运行与行为测试不需要该组。
- 安装命令：`uv sync --locked`；运行也带 `--locked`。
- 锁文件使用阿里云公开 PyPI 镜像，安装需要能够访问该源。

首次安装可能联网。依赖安装完成后，运行前三章无需模型凭据或模型服务。
