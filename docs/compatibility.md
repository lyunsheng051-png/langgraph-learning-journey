## 依赖复现

第 1、2、4 篇的直接运行依赖只有 LangGraph；第 3 篇增加 python-docx 和 pypdf 进行格式解析。前四篇没有主动使用模型、检查点、网络 SDK 或追踪服务。第 5 篇使用 langchain-deepseek、langchain-core 消息和 Pydantic，直接声明 openai 以捕获其 SDK 请求异常；该 SDK 在本章访问的是 DeepSeek 服务。

- Python 范围：`>=3.12,<3.13`；`.python-version` 指定 `3.12`。
- 第 1 篇声明 `langgraph>=1.0,<2.0`，第 2—5 篇声明 `langgraph==1.2.16`；五章各自的 `uv.lock` 均锁定为 `1.2.16`。
- 第 3 篇的 `fixtures` 依赖组用于重建样例，需要 reportlab；正常运行与行为测试不需要该组。
- 第 5 篇锁定 langchain-deepseek 1.1.1、langchain-core 1.7.0、langchain-openai 1.7.2、openai 3.36.1、Pydantic 2.14.1。独立环境中的版本不影响前四篇。
- 安装命令：`uv sync --locked`；运行也带 `--locked`。
- 锁文件使用阿里云公开 PyPI 镜像，安装需要能够访问该源。

首次安装可能联网。依赖安装完成后，运行前四章无需模型凭据或模型服务。

第 5 篇 mock 无需模型服务；real 使用 DeepSeek 凭据，联网调用可能产生费用。
