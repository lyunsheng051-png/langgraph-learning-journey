# 文档摘要输出

## 固定响应 mock

```powershell
uv run --locked python -m chapter_demo
```

stdout，退出码 0。以下是固定内容，不是模型生成结果：

```text
文档摘要结果
模式：mock（固定响应，未调用模型）
摘要：这份规定说明了出差审批、报销材料与提交时限，以及超标住宿的处理要求。
关键事项：
1. 先提交出差申请，经主管审批后再预订交通和住宿。
2. 报销需提供发票及审批记录，返回后十个工作日内提交。
3. 住宿标准按目的地和职级执行，超标部分需另行说明。

处理日志：
1. 已读取资料：102 字符
2. 已收到摘要响应
3. 摘要结构校验通过
4. 已接受摘要
```

## DeepSeek 真实响应

```powershell
uv run --locked --env-file .env python -m chapter_demo --mode real
```

以下是 `deepseek-flash` 一次实际调用的 stdout，退出码 0；后续运行的措辞与关键事项数量可能不同：

```text
文档摘要结果
模式：real（DeepSeek）
摘要：本资料为学习示例使用的虚构出差规定，涉及出差申请审批、交通住宿预订、报销材料与提交时限以及住宿标准执行。
关键事项：
1. 出差前提交申请，经主管审批后预订交通和住宿
2. 报销需提供发票及审批记录
3. 返回后十个工作日内提交报销
4. 住宿标准按目的地和职级执行
5. 超出住宿标准的部分需另行说明

处理日志：
1. 已读取资料：102 字符
2. 已收到摘要响应
3. 摘要结构校验通过
4. 已接受摘要
```

## 模拟缺字段

```powershell
uv run --locked python -m chapter_demo --mock-case missing-field
```

stderr，退出码 1：

```text
文档摘要结果
模式：mock（固定响应，未调用模型）
状态：未接受摘要
原因：摘要结构校验失败：key_points (missing)

处理日志：
1. 已读取资料：102 字符
2. 已收到摘要响应
3. 摘要结构校验失败
4. 处理结束：未接受摘要
```

## 模拟坏 JSON

```powershell
uv run --locked python -m chapter_demo --mock-case invalid-json
```

stderr，退出码 1：

```text
文档摘要结果
模式：mock（固定响应，未调用模型）
状态：未接受摘要
原因：摘要结构校验失败：JSON (json_invalid)

处理日志：
1. 已读取资料：102 字符
2. 已收到摘要响应
3. 摘要结构校验失败
4. 处理结束：未接受摘要
```

其他故障分别报告“模型请求超时”“模型拒绝了本次请求”或“模型输出达到长度上限”，不生成成功摘要，退出码均为 1。缺少真实模式所需的环境变量时为配置错误，退出码 2。
