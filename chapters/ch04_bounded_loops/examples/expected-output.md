# 运行输出

## 默认：最后一次允许的修正后通过

```powershell
uv run --locked python -m chapter_demo
```

stdout，退出码 0：

```text
报告检查结果
状态：通过
修正次数：2 / 2
检查次数：3
剩余问题：无

当前草稿：
# 出差资料整理

出差前需要审批，报销时需要提供发票。

来源：travel_policy.txt

处理日志：
1. 开始：最多修正 2 次
2. 第 1 次检查：缺少标题、缺少来源行
3. 第 1 次修正：补上标题
4. 第 2 次检查：缺少来源行
5. 第 2 次修正：补上来源行
6. 第 3 次检查：通过
7. 结束：报告通过检查
```

## 一次修正后耗尽预算

```powershell
uv run --locked python -m chapter_demo --max-repairs 1
```

stderr，退出码 1：

```text
报告检查结果
状态：修正次数用尽
修正次数：1 / 1
检查次数：2
剩余问题：缺少来源行

当前草稿：
# 出差资料整理

出差前需要审批，报销时需要提供发票。

处理日志：
1. 开始：最多修正 1 次
2. 第 1 次检查：缺少标题、缺少来源行
3. 第 1 次修正：补上标题
4. 第 2 次检查：缺少来源行
5. 结束：修正次数用尽，保留当前草稿
```

## 修正完全无效

```powershell
uv run --locked python -m chapter_demo --repair-mode unchanged
```

stderr，退出码 1：

```text
报告检查结果
状态：修正次数用尽
修正次数：2 / 2
检查次数：3
剩余问题：缺少标题、缺少来源行

当前草稿：
出差前需要审批，报销时需要提供发票。

处理日志：
1. 开始：最多修正 2 次
2. 第 1 次检查：缺少标题、缺少来源行
3. 第 1 次修正：保持原文（无效修正实验）
4. 第 2 次检查：缺少标题、缺少来源行
5. 第 2 次修正：保持原文（无效修正实验）
6. 第 3 次检查：缺少标题、缺少来源行
7. 结束：修正次数用尽，保留当前草稿
```

## 图执行上限过小

```powershell
uv run --locked python -m chapter_demo --recursion-limit 3
```

stderr，退出码 3：

```text
图执行中断：达到 recursion_limit=3 的执行上限。
这次没有得到业务完成结果；检查循环条件，或为正常路径设置足够的图执行上限。
```

## 其他边界

| 参数 | 状态 | 修正次数 | 检查次数 | 退出码 |
| --- | --- | --- | --- | --- |
| `--sample complete` | 通过 | 0 | 1 | 0 |
| `--sample complete --max-repairs 0` | 通过 | 0 | 1 | 0 |
| `--max-repairs 0` | 修正次数用尽，仍缺标题和来源 | 0 | 1 | 1 |
| `--max-repairs 10 --repair-mode unchanged` | 修正次数用尽 | 10 | 11 | 1 |
| `--max-repairs -1`、`--max-repairs 11` | 参数错误 | — | — | 2 |
| `--recursion-limit 0` | 参数错误 | — | — | 2 |

`--show-state` 会在业务结果后追加最终状态 JSON；图执行异常时不会伪造最终状态。
